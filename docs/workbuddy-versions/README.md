# WorkBuddy 版本定制能力

BuddyHue 按 WorkBuddy 的**精确版本**维护一份定制能力文档。主题包仍可声明一个经过验证的版本范围，但任何新增选择器或能力都必须先在精确版本上完成只读快照、应用、验证与恢复闭环。

## 已验证版本

| --- | --- | --- | --- | --- |

## 文档维护规则

1. 每个精确版本一个文件：`<version>.md`。
2. 只记录真实探测到的稳定语义类、状态属性和能力；哈希类只作为诊断证据，不能进入主题契约。
3. 版本升级后重新运行 `doctor`、`probe`、`snapshot`、`preflight`、`apply`、`verify` 与截图检查。
4. 若 landmark 或安全能力发生变化，先更新 adapter 与测试，再扩大主题兼容范围。
5. 未完成闭环验证的版本不得加入“已验证版本”表，也不得静默使用 `--allow-untested`。

新增版本时复制 [模板](TEMPLATE.md)，不要直接覆盖旧版本记录。
