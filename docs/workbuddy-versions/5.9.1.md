## 支持的皮肤能力

- CSS：普通选择器、属性选择器、伪元素、媒体查询、渐变、阴影、圆角、`backdrop-filter` 与 reduced-motion 覆盖。
- 图片：PNG、JPEG、WebP、GIF；包内图片通过 `--codedrobe-image-<id>` 变量使用。
- 主题状态：根元素会出现 `.codedrobe-theme` 与 `.codedrobe-host-workbuddy`，可用于收敛作用域。
- 交互状态：可使用 `:hover`、`:focus-visible`、`[aria-current='page']`、`[aria-selected='true']` 与 `[data-state='active']`。
- 验证：应用后检查 stylesheet、主题 ID / 版本、布局溢出和已声明 landmark。

## 不支持或禁止

- 主题包不能包含 JavaScript、renderer 插件、生命周期脚本、`@import`、远程图片、远程 CSS 或外部字体。
- 不允许修改或新增业务 DOM、替换业务文案、改变控件行为、读取聊天正文或表单值。
- 不修改 `app.asar`、应用签名或系统安全设置。
- `_grid_*` 等哈希类会随构建变化，只能用于本次诊断，不能作为主题契约。
- 右侧浏览器 / artifact 面板使用独立布局；未经单独验证前只继承全局色与 focus，不做结构性覆盖。
- 宿主级主题切换当前未启用；本版本通过 renderer CSS 注入完成皮肤应用。

## 5.9.1 的实现注意点

- `.conversation-list-content` 与 `.conversation-list-footer` 默认带不透明浅色背景；深色侧栏必须显式透明化这些内层。
- 浅色模式的部分内层样式具有较高优先级；定制时应使用 `html.codedrobe-theme body.cb-light` 收敛并提升作用域，不能只依赖裸类名。
- 任务卡标题和时间使用独立的 `color` / `-webkit-text-fill-color`；深色侧栏需在 `.conversation-agent-card` 内同时覆盖两者。
- `.collapsible-section-header` 默认为不透明浅蓝底；深色侧栏需改为透明或低对比表面。
- `.conversation-list-tab-row.active` 会在选中时绘制浅蓝外层底色，而 `.conversation-list-tab-button.active` 也会参与 hover；需要清空外层行，并在按钮层统一 hover / selected 状态。
- 一级导航选中态应直接覆盖 `box-shadow`；当前联合主题使用四周细描边和顶部高光，不使用容易形成通用聊天产品观感的左侧强调竖线。
- `.conversation-list-version-badge` 是静态版本信息，不应与 `.conversation-list-tab-beta` 共用状态徽标底色；前者保持透明，后者保留胶囊状态表达。
- `.conversation-item` 本身没有圆角，悬浮背景必须只画在其内部 `.conversation-agent-card` 上，否则会出现方角底色。
- `.wb-home-route` 默认带不透明背景；要显示主工作区背景素材，需显式设为透明。
- 普通任务的 `.workbuddy-topbar` 嵌套在 `.conversation-page-chrome` 内，不会被主工作区“直接子级 header”规则命中；需要单独与空间/项目标题栏同步表面与分隔线。
- 项目对话的输入区稳定层级为 `.project-detail-view__input-area`；装饰图放在 `.project-detail-view__main::after`，内容层设为更高层级，可避免遮挡输入框和发送按钮。
- `[contenteditable='true']` 聚焦时不建议直接绘制 outline；5.9.1 的编辑器本身嵌套在有完整边界的输入容器内，内部描边会形成突兀的“双框”。
- `.cr-send-button` 在禁用时同时带 `disabled` 属性和 `.wb-button--disabled`；禁用箭头有独立低透明 fill，必须与按钮表面一起覆盖，不能沿用可发送态的高饱和底色。
- 当前首页主内容最大宽度约 800px；背景细节应放在两侧，中央保持低对比，避免影响长文本与输入区。
- 侧栏当前宽度约 280px，主工作区与侧栏在 1645×1050 视口下均无横向溢出。
